# Journal des versions · Changelog

Chaque section est reprise telle quelle comme notes de la version sur GitHub (`scripts/release.sh`).
Each section is used as-is for the GitHub release notes.

## 0.2.0 — 2026-11-07

**Français**
- Première version publiée, à télécharger depuis GitHub.
- Vigie parle français et anglais ; la langue se choisit dans le menu ⚙︎.
- Section Docker : conteneurs regroupés par projet Compose, arrêt en deux clics, place prise par Docker et commandes de nettoyage à copier.
- Espace disque : jauge dans le panneau, alerte sous 15 % (barre des menus, bandeau, notification).
- Mises à jour : « Rechercher une mise à jour » dans le menu ⚙︎, et vérification automatique une fois par jour (désactivable).

**English**
- First published version, downloadable from GitHub.
- Vigie speaks French and English; pick the language in the ⚙︎ menu.
- Docker section: containers grouped by Compose project, two-click stop, Docker's disk usage and cleanup commands to copy.
- Disk space: gauge in the panel, warning below 15% (menu bar, banner, notification).
- Updates: “Check for updates” in the ⚙︎ menu, plus an automatic check once a day (can be turned off).
